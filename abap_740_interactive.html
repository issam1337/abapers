Déclarations en ligne

🔷 DATA — Variable simple
Avant 7.40
DATA: text TYPE string.
text = 'ABC'.
Avec 7.40
DATA(text) = 'ABC'.
🔷 LOOP AT — Work area inline
Avant 7.40
DATA wa LIKE LINE OF itab.
LOOP AT itab INTO wa.
  ...
ENDLOOP.
Avec 7.40
LOOP AT itab
  INTO DATA(wa).
  ...
ENDLOOP.
🔷 SELECT INTO TABLE — Inline + @
Avant 7.40
DATA itab TYPE TABLE OF ekko.
SELECT * FROM ekko
  INTO TABLE itab
  WHERE ebeln = lv_ebeln.
Avec 7.40
SELECT * FROM ekko
  INTO TABLE @DATA(itab)
  WHERE ebeln = @lv_ebeln.

Expressions de tableau

  

  

    

      

        
📋 Read Table par index

        

          
Avant
READ TABLE itab
  INTO wa INDEX 2.

          
7.40
wa = itab[ 2 ].

        

      

      

        
📋 Read Table par clé

        

          
Avant
READ TABLE itab
  INTO wa
  WITH KEY
    matnr = 'M001'.

          
7.40
wa = itab[
  matnr = 'M001' ].

        

      

      

        
📋 Vérifier l'existence

        

          
Avant
READ TABLE itab
  TRANSPORTING NO FIELDS
  WITH KEY matnr='M001'.
IF sy-subrc = 0. ... ENDIF.

          
7.40
IF line_exists(
  itab[ matnr='M001'] ).
  ...
ENDIF.

DATA(lv_n)

Opérateur VALUE

  

  

    

      

        
💎 VALUE — Initialiser une structure

        

          
Avant 7.40
DATA: ls_s TYPE ty_s.
ls_s-col1 = 1.
ls_s-col2 = 2.
ls_s-col3 = 'ABC'.

          
Avec 7.40
ls_s = VALUE #(
  col1 = 1
  col2 = 2
  col3 = 'ABC' ).

        

      

      

        
💎 VALUE — Remplir une table interne

        

          
Avant 7.40
ls_s-col1 = 1. ls_s-col2 = 1.
APPEND ls_s TO lt_s.
ls_s-col1 = 2. ls_s-col2 = 2.
APPEND ls_s TO lt_s.

          
Avec 7.40
lt_s = VALUE #(
  ( col1=1 col2=1 )
  ( col1=2 col2=2 ) ).

    04
    
Opérateur FOR

  

  

    

      

        
🔁 FOR — Forme condensée en une ligne

        

          
Avant 7.40
LOOP AT gt_ships
  INTO gs_ship
  WHERE route='R0001'.
  gs_city=gs_ship-city.
  APPEND gs_city
    TO gt_citys.
ENDLOOP.

          
Avec 7.40
DATA(gt_citys) =
 VALUE ty_citys(
  FOR ls_s IN
    gt_ships
  WHERE( route=
    'R0001' )
  ( ls_s-city ) ).

        

      

      

        
🔁 FOR avec BASE — Append incrémental

        

          
Avant 7.40
LOOP AT gt_ships
  INTO gs_ship
  WHERE route='R0001'.
  APPEND VALUE ty_citys(
    city=gs_ship-city)
  TO gt_citys.
ENDLOOP.

          
Avec 7.40
LOOP AT gt_ships
  INTO gs_ship
  WHERE route='R0001'.
gt_citys=VALUE ty_citys(
 BASE gt_citys
 (city=gs_ship-city)).
ENDLOOP.

Simulateur FOR Loop
Filtrer gt_ships WHERE route = R0001 → extraire les villes

    05
    
COND & SWITCH

  

  

    

      

        
🔀 COND — Expression conditionnelle

        

          
Avant (CASE)
CASE lv_mult.
 WHEN 0.
   lv_m = 100.
 WHEN 1.
   lv_m = 10.
 WHEN 3.
   lv_m = '0.1'.
 WHEN OTHERS.
   lv_m = 1.
ENDCASE.

          
7.40 COND
lv_m = COND #(
 WHEN lv_mult=0
   THEN 100
 WHEN lv_mult=1
   THEN 10
 WHEN lv_mult=3
   THEN '0.1'
 ELSE 1 ).

        

      

      

        
COND vs SWITCH — différence clé

        

          

            
COND #( WHEN expr )

            
Conditions booléennes arbitraires. Équiv. IF/ELSEIF.

          

          

            
SWITCH #( var WHEN )

            
Variable discrète. Équiv. CASE/WHEN.

          

        

      

    

    
    

      

        🎛️
        
Testeur COND / SWITCH Live
Bougez le curseur → voyez quelle branche s'active

SWITCH expression

            
WHEN 0 THEN 100

            
WHEN 1 THEN 10

            
WHEN 3 THEN 0.1

            
ELSE 1

CORRESPONDING & Concaténation

  

  

    

      

        
🔄 CORRESPONDING — Copie par champ

        

          
Avant
CLEAR ls_line2.
MOVE-CORRESPONDING
  ls_line1
  TO ls_line2.

          
7.40
ls_line2 =
 CORRESPONDING #(
   ls_line1 ).

        

      

      

        
🔗 Concaténation — String templates

        

          
Avant
CONCATENATE
  'Hello' 'world'
  INTO lv_out
  SEPARATED BY
    space.

          
7.40
DATA(lv_out) =
  |Hello| &
  | |   &
  |world|.

        

      

      

        
🔗 String template — Interpolation { }

        

          
Avant
CONCATENATE
  'Val: ' lv_v
  INTO lv_out.

          
7.40
DATA(s) =
  |Val: { lv_v }|.
